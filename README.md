## 三、問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為在 Python 中，加上引號的 `"4"` 是**字串（`str`）**型別，代表的是文字而非數值。在計算每人費用時需要執行除法運算（`總金額 / 人數`），而 Python 不允許將數字（`float` 或 `int`）直接除以字串，否則會發生 `TypeError` 錯誤，因此必須先用 `int("4")` 將其轉為整數 `4` 才能進行數學運算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
- **計算結果**：應付總額會變成 **1,210 元**。
  - 算式：先扣折價券 `1200 - 100 = 1100` 元；再算 10% 服務費 `1100 × 0.10 = 110` 元；最後相加 `1100 + 110 = 1210` 元。
- **不同的原因**：因為服務費的計算基準（母數）不同。題目規定服務費必須以「原始餐費（1,200 元）」計算，服務費是 120 元；若先扣掉 100 元折價券再算服務費，折價券的 100 元就少算了 10% 的服務費（10 元），導致總金額少了 10 元。
